# 청라로지스 실재고 실사 앱

창고 실재고 실사용 모바일 웹앱. 파일 하나로 동작하며 오프라인에서도 실행됩니다.

## 올리는 법 (GitHub Pages)

1. 깃허브에서 새 저장소 생성 (Public)
2. 이 폴더의 파일 4개를 그대로 업로드 (index.html · sw.js · icon-192.png · icon-512.png)
3. Settings → Pages → Source: `main` 브랜치 / `/ (root)` → Save
4. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 로 접속

## 휴대폰 홈 화면에 추가

- **안드로이드(Chrome)**: 주소창 우측 ⋮ → "홈 화면에 추가" / "앱 설치"
- **아이폰(Safari)**: 하단 공유 버튼 → "홈 화면에 추가"

아이콘을 누르면 주소창 없는 전체화면으로 바로 열립니다.
