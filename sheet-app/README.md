# 재고표 연동 실사 앱 (Google Apps Script)

재고표(구글 시트)와 자동으로 연결되는 실사 입력 앱입니다.
관리자 한 사람만 입력하고, 직원·운영팀은 구글 시트에서 보기만 합니다.

> 이 폴더는 Apps Script용 소스 보관용입니다. GitHub Pages로 열어서 쓰는 앱이 아닙니다.
> 루트의 `index.html`(기존 단독 실사 앱)과는 별개입니다.

## 파일

- `Code.gs` — 서버 코드. 재고표 시트 읽기/쓰기, 이력 기록, 박스/PLT 설정
- `Index.html` — 입력 화면 (유통기한 · PLT · 낱BOX → BOX 자동 계산)

## 설치

1. 재고표 구글 시트 → 확장 프로그램 → Apps Script
2. `Code.gs` 내용 붙여넣기, 파일 추가(HTML) 이름 `Index` 로 `Index.html` 붙여넣기
3. 함수 `setup` 한 번 실행 (권한 승인)
4. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 나만)
5. 코드를 고친 뒤에는 배포 관리 → ✏ → 새 버전으로 다시 배포

## 시트 구조 (재고표)

A 품목 · B 유통기한 · C~R 출고1~8(날짜, 수량) · S 잔량 · T 품목 합계 · U 입고 날짜 · V 입고 수량
(6행부터 데이터)
